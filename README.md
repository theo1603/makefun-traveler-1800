One sentence of at most 200 characters explaining the modern internet to a time traveler arriving from 1800: a single road joining every post office, library, and market on earth, built only from things a person from 1800 already knows. `main.py` writes that sentence to `/output/entry.txt`. Deterministic, Python 3.13 stdlib only, no network.

## Run it

```sh
python3 main.py
```
